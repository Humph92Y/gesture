에어드럼 테스트

카메라만으로 허공 드럼 · 1차 테스트 버전
① 오른쪽에서 카메라 켜기를 눌러 주세요.
머리부터 발끝까지 화면에 나오도록 2~3m 떨어져 서 주세요.

사용 방법

  1. 카메라 켜기 → 온몸(발까지)이 화면에 나오게 서기
  2. 캘리브레이션: 화면 안내대로 드럼 자리와 발 높이 맞추기 (약 1분)
  3. 자유롭게 쳐 보기: 주먹을 스틱 잡듯 쥐고 들었다 내려치기. 오른발 들었다 내리기 = 킥, 왼발 들기 = 하이햇 열림
  4. 테스트 시작 → 화면 안내와 박자 소리에 맞춰 치기(약 80초) → 끝나면 보고서가 자동 저장
  5. 보고서 목록에서 전체 내보내기 → 받은 파일을 Claude에게 보내 주면 분석해서 고칩니다

1카메라

노트북 내장 캠, USB 웹캠, 휴대폰(이 페이지를 휴대폰에서 열기) 모두 됩니다.

2캘리브레이션

  1. 자세 확인 (온몸이 보이는지)
  2. 기준 측정 (3초 가만히)
  3. 드럼 자리 정하기 (드럼마다 3번)
  4. 킥 높이 (오른발 3번)
  5. 하이햇 페달 높이 (왼발 3번)

3테스트

BPM
학습용 기록은 감도 조정에, 검증용 기록은 정확도 판단에만 씁니다.
